# 📊 E-Commerce Sales & Customer Behavior Analysis

## 📌 Project Overview
This project analyzes retail transaction data to uncover revenue trends, top-performing product categories, regional performance, and customer payment preferences. 

## 🛠️ Tools & Technologies Used
- **Language:** Python 3
- **Libraries:** Pandas (Data Cleaning & Aggregation), Matplotlib (Data Visualization)
- **Dataset:** `sales_data.csv`

## 🔍 Key Business Questions Answered
1. What is our total revenue and average order value (AOV)?
2. Which product categories generate the highest sales?
3. Which geographical regions bring in the most revenue?
4. What payment methods do customers prefer?

## 📈 Key Insights & Findings
- **Total Revenue:** **$1,730.00** across **12 orders**, with an Average Order Value (AOV) of **$144.17**.
- **Top Product Category:** **Electronics** led all categories with **$820.00** in revenue (**47.4%** of total sales), followed by **Apparel** ($510.00) and **Home & Kitchen** ($400.00).
- **Top Performing Region:** The **North** region generated the highest revenue at **$550.00**, followed by the South ($420.00).
- **Payment Preferences:** Digital payments dominate—**UPI** (5 orders) and **Credit Cards** (5 orders) accounted for **83.3%** of all transactions.

## 🚀 How to Run This Project
1. Clone this repository or download `sales_data.csv` and `analysis.py`.
2. Install required libraries:
   `pip install pandas matplotlib`
3. Run the script:
   `python analysis.py`
